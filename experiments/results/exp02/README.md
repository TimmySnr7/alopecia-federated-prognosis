# Experiment 02 Results

Experiment 02 records the transition from Experiment 01 feasibility work to a
visual-plausibility-first, QA-gated proxy supervision pipeline.

The experiment is closed out in `final_report.md`.

Result packages:

- `scorer_gate_v1/`: feature-based severity-scorer entry gate for Experiment 02.
- `source_aware_proxy_batch_v1/`: source-aware mask QA, proxy batch evaluation,
  and curated proxy-pair manifest.

Large visual contact sheets were generated and reviewed locally, but are not
tracked in Git. The machine-readable summaries and CSV manifests are tracked so
the run remains auditable without committing image-heavy artefacts.
